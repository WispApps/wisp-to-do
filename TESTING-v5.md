# Wisp To Do v5 — проверка на телефоне

В этой версии изменены первоначальная настройка, локализация и история экранов. Схема базы данных и ключ существующей резервной копии не меняются. Не удаляйте приложение и не очищайте его данные при обновлении.

1. При обновлении первоначальная настройка показывается один раз повторно. Выберите язык; все подписи должны сразу измениться.
2. Продолжите к фразе. Вернитесь кнопкой в приложении или системной кнопкой к языкам. Смените язык и снова продолжите: фраза должна остаться прежней.
3. Копирование требует подтверждения предупреждения о буфере обмена. Для завершения введите первый и последний элементы фразы целиком (включая дефис), подтвердите сохранение отдельно.
4. После фразы можно разрешить уведомления или пропустить запрос.
5. Настройки → язык: проверьте все десять языков, затем перезапустите приложение. Названия собственных списков и задач не переводятся.
6. Главная → проект → список → системная «Назад»: должен открыться проект; ещё раз — главная.
7. Поиск → введите запрос → откройте список → «Назад»: должен сохраниться запрос. Проверьте также поворот телефона.
8. Открытый диалог должен закрываться первым нажатием «Назад» без выхода с родительского экрана.

Проверены XML, совпадение ключей и параметров переводов, покрытие текстовых подписей. Сборка APK и тесты на Android в среде подготовки не выполнялись: Android SDK отсутствует. Выполните `./gradlew.bat assembleDebug` в PowerShell, затем `./gradlew.bat installDebug` с подключённым телефоном.

Ограничения унаследованной облачной реализации: кнопки Nextcloud выполняют зашифрованную выгрузку и восстановление, а не автоматическую двустороннюю синхронизацию. Локальная Room-база не зашифрована. Экран ввода существующей фразы для восстановления на новом устройстве ещё не реализован. Фраза сама по себе не заменяет резервную копию. Это обновление не устраняет перечисленные ограничения.
